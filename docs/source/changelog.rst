Changelog
=========

2026-11
-------

* Factory with ``create_component_by_name``, ``create_object_by_name``, ``is_type_name_registered`` and ``print``.
* ``uvm_component_utils`` registers a class with the factory.
* Run-time test selection with ``run_test("name")`` and ``+UVM_TESTNAME``.
* ``uvm_test`` is abstract, as in standard UVM.
* Tests renamed ``t0`` to ``t7``.
* ``make check`` and ``make gold`` compare runs with golden logs.
